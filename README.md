# Bubble Pop — локальное веб-приложение

Готовая пользовательская версия для текущего этапа проекта.

## Что реализовано

- современный адаптивный веб-интерфейс;
- главное меню;
- экран настройки игрока;
- три уровня сложности;
- игровое поле;
- таймер;
- случайное появление пузырей;
- анимация пузырей;
- эффект лопания и частицы;
- подсчёт очков;
- экран результата;
- таблица лидеров;
- PostgreSQL;
- FastAPI;
- API `GET /api/scores`;
- API `POST /api/scores`;
- API `GET /api/health`.

## Сейчас НЕ включено

Docker, docker-compose, CI/CD и деплой — это следующий этап автоматизации.

## Запуск

Требуется Python 3 и локальный PostgreSQL.

Создай базу:

    createdb bubble_pop

В корне проекта:

    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    cp .env.example .env

Открой `.env` и укажи пароль пользователя PostgreSQL.

Запусти сервер:

    uvicorn app.main:app --reload

Затем открой:

    http://127.0.0.1:8000

## Тесты

После установки зависимостей:

    pytest

Если PostgreSQL пока не настроен, само веб-приложение всё равно открывается, но сохранение и таблица лидеров будут недоступны.
